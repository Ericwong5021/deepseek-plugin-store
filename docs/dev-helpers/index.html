Installing

# from npm (prebuilt)
dsh plugin --profile web add <npm-package>

# from GitHub (first run asks for allowBuilds approval — follow the hint, retry)
dsh plugin --profile web add github:<owner>/<repo>

GitHub-sourced plugins run build scripts on your machine at install time. Only install sources you trust, and pin a commit (github:owner/repo#sha).

Get your plugin listed

All listed plugins must declare dsh.bundle in the root package.json. Add the dsh-plugin topic for automatic discovery, or submit an Editor Pick through a pull request.

Plugins are developed by their respective authors; listing is not an endorsement. Installing runs third-party code — review the source and proceed at your own risk.
