# Collaboration / 合作说明

## Automatic listing / 自动收录

为公开仓库添加 [`dsh-plugin`](https://github.com/topics/dsh-plugin) Topic 后，目录会在每小时同步时自动收录，无需提交 Pull Request。

Add the [`dsh-plugin`](https://github.com/topics/dsh-plugin) topic to a public repository for automatic listing during the hourly sync. No pull request is required.

## Editor Picks / 编辑精选

编辑精选用于收录维护者人工审核、主动添加的插件。申请时请修改 `data/editor-picks.json`，每项填写 `repository`，需要覆盖仓库简介时可填写 `summary`。

Editor Picks are manually reviewed and maintained. Add the repository to `data/editor-picks.json` with a `repository` field and an optional `summary` when the catalog should override the GitHub description.

提交前请确认仓库公开可访问、与 DeepSeek Harness 生态相关、安装标识有效，且提交者有权代表该项目。

Before submitting, confirm that the repository is public, relevant to the DeepSeek Harness ecosystem, has a valid install identifier, and that the submitter is authorized to represent it.

## Review / 审核

编辑精选由维护者决定是否收录、调整描述或移除。收录不代表 DeepSeek 或本项目对插件的安全性、质量或兼容性背书。

Maintainers decide whether an Editor Pick is accepted, edited, or removed. Listing does not imply endorsement of security, quality, or compatibility by DeepSeek or this project.
